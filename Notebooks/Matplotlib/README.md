# Taller Matplotlib y Visualizaciones

Descripcion

Esta carpeta contiene el desarrollo de la evidencia enfocada en la generacion de visualizaciones con Matplotlib aplicada al dataset del proyecto. A traves del notebook se trabaja la estructura de una grafica, la diferencia entre el enfoque `pyplot` y el enfoque orientado a objetos, y la construccion de graficas univariantes, bivariantes y categoricas.

Objetivo

Comprender y aplicar el uso de Matplotlib para representar datos de forma clara, tecnica y reproducible, seleccionando tipos de graficas adecuados segun el comportamiento de las variables analizadas.

Pregunta de analisis

Por que es importante seleccionar correctamente el tipo de grafica al analizar un conjunto de datos?

Seleccionar correctamente el tipo de grafica es importante porque cada visualizacion comunica la informacion de manera diferente. Una grafica adecuada permite resaltar patrones, distribuciones, relaciones o comparaciones de forma clara, mientras que una grafica mal elegida puede ocultar hallazgos relevantes o generar interpretaciones equivocadas.

Ademas, el tipo de variable influye directamente en la visualizacion mas conveniente. Por ejemplo, una variable numerica puede analizarse con histogramas o boxplots, mientras que una variable categorica suele representarse mejor con graficas de barras. Cuando esta seleccion se hace de forma tecnica, el analisis resulta mas preciso, comprensible y util.

En conjunto, elegir bien una grafica mejora la comunicacion de resultados, fortalece la interpretacion del dataset y permite que el proceso analitico sea mas coherente con los objetivos del proyecto.

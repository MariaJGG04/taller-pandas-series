# Taller Clasificacion de Variables y Seleccion de Graficas

Descripcion

Esta carpeta contiene el desarrollo de la evidencia orientada a la identificacion, clasificacion y analisis de las variables del dataset del proyecto. En el notebook se estudia el tipo de cada variable, su subtipo estadistico y la seleccion de la visualizacion mas adecuada segun su naturaleza y el objetivo del analisis.

Objetivo

Reconocer la importancia de clasificar correctamente las variables de un dataset para justificar tecnicamente la seleccion de graficas y mejorar la calidad del analisis de datos.

Pregunta de analisis

Como contribuye la clasificacion de variables a una mejor interpretacion de los datos en un proyecto de analisis?

La clasificacion de variables contribuye a una mejor interpretacion de los datos porque permite entender que representa cada campo del dataset y como debe analizarse. Al distinguir entre variables cualitativas y cuantitativas, asi como entre subtipos nominales, ordinales o discretos, es posible elegir metodos de analisis y visualizaciones coherentes con la naturaleza de la informacion.

Ademas, esta clasificacion reduce el riesgo de cometer errores metodologicos, como aplicar operaciones numericas a categorias o utilizar graficas que no reflejan correctamente el comportamiento de los datos. Esto mejora tanto la precision tecnica como la claridad de los resultados obtenidos.

En conjunto, clasificar las variables es una etapa fundamental porque ordena el proceso analitico, facilita la toma de decisiones y permite construir interpretaciones mas solidas, justificadas y comprensibles.
